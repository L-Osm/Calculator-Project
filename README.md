### No Dependencies Calculator:

Works by entering a sequence of values and operations [e.g. 4 * 2 / 5] and printing the answer out in a float format.

## Features:

No dependencies required to run the program.
Uses basic arithmetic operators (multiply, divide, add + subtract), brackets, can take decimals + negative numbers.
Developed with Classes + Objects to use less code.
Uses a Recursive Descent Parser to make the order of operations be BODMAS/BIDMAS [calculator accurate].
Has error handling with unknown characters or invalid expressions.

## Planned Features:

Implicit multiplication with e.g. 4(5) instead of 4 * 5.
Full bracket functionality similar to a physical calculator.
Using exponents in calculations.
Using square roots, with a binary search algorithm to approximate the final value.
Using mathematical constants [e.g pi, e, i (imaginary) and using complex numbers].
Adding factorial(!) and modulo(%) support.
Storing previous answers (ans) and keeping a list of previous results (history).
Storing user defined variables (e.g. x = 5) for use in calculations.
Use of trigonometric functions (with manual approximation of values).
